# WAQAR — Privacy Policy (وقار — سياسة الخصوصية)

This repository hosts only the public Arabic privacy policy of the WAQAR iPhone app, served by GitHub Pages.
It contains no application source code.

- `index.html` is a static page: no scripts, no cookies, no analytics, no external fonts.
- It is generated from the private project's `docs/app-store/privacy/PRIVACY_POLICY_AR.md`. Edit the policy there,
  rebuild, then replace `index.html` here and update the effective date.
