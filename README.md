# WAQAR — Privacy Policy (وقار — سياسة الخصوصية)

This repository hosts only the public Arabic pages of the WAQAR iPhone app, served by GitHub Pages.
It contains no application source code.

- `index.html`: privacy policy (سياسة الخصوصية).
- `support.html`: support and contact (الدعم والتواصل).
- Static pages: no scripts, no cookies, no analytics, no external fonts or images.
- Both are generated from the private project's `docs/app-store/privacy/` (`PRIVACY_POLICY_AR.md`, `SUPPORT_AR.md`).
  Edit them there, rebuild, then replace the files here.
